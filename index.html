TUDO ÀS CLARAS

Antes do
primeiro play.

O Atlas AI é gratuito?+

O Atlas é um editor de código aberto, sem mensalidade do editor. Para usar os recursos de inteligência artificial, você configura sua própria chave da Anthropic e paga o consumo diretamente à API.

Preciso saber programar para instalar?+

A instalação começa com um comando no Terminal ou PowerShell. O instalador verifica as dependências e prepara o ambiente. O primeiro download pode levar alguns minutos. Consulte o guia no GitHub se o seu sistema precisar de algum ajuste.

Funciona em qual sistema operacional?+

Você pode instalar no macOS, Windows ou Linux. Também existe a opção de rodar em uma VPS própria, seguindo o guia de implantação disponível no repositório.

Que tipo de vídeo posso criar?+

O Atlas foi pensado para anúncios e VSLs verticais: reúne transcrição, cortes, legendas, letreiros, B-roll e efeitos sonoros, com templates reutilizáveis, prévia e renderização.

O editor funciona totalmente offline?+

O editor roda no seu computador, mas os recursos de IA que usam a API e as buscas de B-roll precisam de conexão com a internet.
